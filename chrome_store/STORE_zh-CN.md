# 一键标签去重分组管理器 (One-click Tab Manager) - 简体中文 / Simplified Chinese

**瞬间告别标签页过载。一键标签管理器是一款高性能的 Chrome 扩展程序，旨在通过一键点击来组织、分组和去除重复的浏览器标签页。**

收回您的工作空间并节省系统内存。无论您在多个窗口中处理 10 个还是 100 多个标签页，此扩展程序都能提供一种快速、确定的方式来保持井然有序，无需手动操作。

### 🚀 核心功能

- **⚡ 智能标签分组：** 根据域名或自定义规则自动对标签页进行分组。只需几秒钟即可将杂乱的标签栏变成井井有条的工作区。
- **🧹 全局去重：** 查找并关闭所有打开窗口中的重复 URL，以释放 RAM 并减少杂乱。
- **🗑️ 自动删除规则：** 自动关闭特定域名的标签页，不再保留不需要的页面。
- **📂 窗口管理：** 按窗口对标签页进行分组，合并分散的标签页，甚至限制您希望保留的打开窗口数量。
- **🛡️ 手动分组保护：** 您的自定义命名分组将保持完整。还可选择对手动分组内的标签页进行排序。
- **🔗 高级拆分与命名：** 按 URL 路径对标签页进行分组（例如，为不同的 GitHub 组织创建独立分组），并为特定域名指定自定义名称。
- **✨ 简洁的标签栏：** 可选择解散仅包含一个标签页的分组，让您的工作区保持绝对整洁。
- **🏎️ 零闪烁性能：** 采用原子执行逻辑构建，确保标签页平滑、无抖动地移动，并保持浏览器的最佳稳定性。
- **🌍 多语言支持：** 现已支持英语、简体中文、繁体中文、日语和西班牙语！

### 🛡️ 隐私与性能

- **100% 隐私安全：** 所有处理均在您的机器上本地进行。无需跟踪、无需数据收集，也无需云端同步。
- **资源高效：** 所有处理均在本地完成，确保不会影响 CPU 和电池寿命。
- **专为高级用户优化：** 专为稳定性和速度而设计，即使在多显示器设置中打开了数百个标签页也能轻松应对。

### 💡 为什么选择一键标签管理器？

大多数标签页管理器要么过于繁琐，要么干扰性太强。一键标签管理器专为速度和可靠性而打造，就像一把精确的手术刀，每次都能完全按照您的意愿清理浏览器会话。
