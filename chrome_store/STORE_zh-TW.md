# 一鍵分頁去重分組管理器 (One-click Tab Manager) - 繁體中文 / Traditional Chinese

**瞬間告別分頁過載。一鍵分頁管理器是一款高效能的 Chrome 擴充功能，旨在透過一鍵點擊來組織、分組和去除重複的瀏覽器分頁。**

收回您的工作空間並節省系統記憶體。無論您在多個視窗中處理 10 個還是 100 多個分頁，此擴充功能都能提供一種快速、確定的方式來保持井然有序，無需手動操作。

### 🚀 核心功能

- **⚡ 智能分頁分組：** 根據網域或自訂規則自動對分頁進行分組。只需幾秒鐘即可將雜亂的分頁列變成井井有條的工作區。
- **🧹 全局去重：** 尋找並關閉所有開啟視窗中的重複 URL，以釋放 RAM 並減少雜亂。
- **🗑️ 自動刪除規則：** 自動關閉特定網域的分頁，不再保留不需要的頁面。
- **📂 視窗管理：** 按視窗對分頁進行分組，合併分散的分頁，甚至限制您希望保留的開啟視窗數量。
- **🛡️ 手動分組保護：** 您的自訂命名分組將保持完整。還可選擇對手動分組內的分頁進行排序。
- **🔗 高級拆分與命名：** 按 URL 路徑對分頁進行分組（例如，為不同的 GitHub 組織建立獨立分組），並為特定網域指定自訂名稱。
- **✨ 簡潔的分頁列：** 可選擇解散僅包含一個分頁的分組，讓您的工作區保持絕對整潔。
- **🏎️ 零閃爍效能：** 採用原子執行邏輯構建，確保分頁平滑、無抖動地移動，並保持瀏覽器的最佳穩定性。
- **🌍 多語言支援：** 現已支援英語、簡體中文、繁體中文、日語和西班牙語！

### 🛡️ 隱私與效能

- **100% 隱私安全：** 所有處理均在您的機器上本地進行。無需追蹤、無需數據收集，也無需雲端同步。
- **資源高效：** 所有處理均在本地完成，確保不會影響 CPU 和電池壽命。
- **專為進階用戶優化：** 專為穩定性和速度而設計，即使在多顯示器設置中打開了數百個分頁也能輕鬆應對。

### 💡 為什麼選擇一鍵分頁管理器？

大多數分頁管理器要麼過於繁瑣，要麼干擾性太強。一鍵分頁管理器專為速度和可靠性而打造，就像一把精確的手術刀，每次都能完全按照您的意願清理瀏覽器會話。
